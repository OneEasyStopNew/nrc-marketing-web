# List

A bordered list (`list`) of 40px rows on `line-hair`: optional leading avatar or icon, title in `t`, subtitle in `s`, right-aligned text or control in `r`. Hover `surface-2`; rows that navigate end in a chevron.

Grouped lists repeat the list under a `cap` label per group (Today, Tomorrow). Use a List for up to a few dozen items with one line each; above that, or with more than three facts per row, use DataTable.
