# ComplianceCheck

The one surface that is violet by design. Head on `regulatory-wash` with the shield; a findings column (each finding: icon in `blocked` or `done`, the rule in plain words, the offending phrase quoted, a suggested rewrite as a link that applies it); a right column with the automated run time, the human approver, an approve or return choice, the IRB number field and the `btn-regulatory` record button.

Rules checked: Meta personal attributes, FDA no-emphasis-on-payment, no audience on a condition, Spanish checked in Spanish, no pixel on study pages, image rights. The automated pass is a draft from a model prompt; the approval is a human's and is written to the audit trail with the IRB number. Never label the automated result "approved".
