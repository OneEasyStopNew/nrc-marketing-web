# AIVideoGenerator

The script comes from copy that already passed the rules (the head says which variant); captions are chosen per language; "No people on screen" is on by default. Right: a storyboard of 9:16 frames with timecodes in mono, and a render queue as a List with a ProgressBar, a Queued badge and a Done row with Preview.

Rendered reels enter the creative library as drafts and go through ComplianceCheck like any creative. Rendering runs in the background; the person can leave the page.
