# Radio

16px circle, `line-strong` border; on is a `brand` 5px ring. Options read as a sentence: inline for two or three short values, stacked for more.

Radio cards (`rc`) carry a title and one line of description inside a `radius-lg` box; the chosen card takes a `brand` border, a 1px ring and `brand-wash`. Use them when the choice needs explaining: stipend method, campaign objective, visit type.

Exactly one option is on. If none may be chosen, add an explicit "None" option rather than allowing an empty group.
