# TwoStepVerification

Six 44×48 mono inputs that advance on entry and accept a pasted code; the active box carries the focus ring. Below: a resend countdown in mono and a recovery-code link; a trust-this-device checkbox (30 days); a 44px Verify button.

Two-step is required for every role that can see a participant name or a financial amount; the slab says so. A wrong code shakes the boxes once and shows "That code did not match. 2 attempts left." in `blocked`.
