# ProgressBar

A 6px track in `surface-3` (`progress-lg` is 10px) with a filled span. Tones: `brand` by default, `done` when the bar measures completion toward a goal, `waiting` when it approaches a cap, `regulatory` for the adverse event window, `blocked` when over. A label row above shows the name and the value in mono.

Stepped progress (`steps`): 28px numbered discs joined by 36px rules; done discs in `done`, the current one ringed in `brand-wash`. The ring form is for a single percentage in a tight space.
