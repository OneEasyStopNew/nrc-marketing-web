# BasicTable

The reading table. Headers in `caption` uppercase `text-faint` with a `line` rule; rows 44px on `line-hair`; primary cell (`p`) in `ink` 500, other cells `text-muted`; numbers right-aligned with tabular figures (`num`); codes in mono.

Modifiers: `table-compact` (36px rows) for reference lists; `table-striped` for wide tables with more than six columns; `table-bordered` wraps the table in a `line` border at `radius-lg`.

Row hover is `surface-2`. A status column uses Badge. No vertical rules, ever.
