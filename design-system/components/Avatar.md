# Avatar

Initials on a solid ground, white text. Ground cycles `avatar-1` to `avatar-4` by the hash of the person's id so a person keeps one colour across the app. Sizes 24 (`av-sm`, table rows), 32 (default), 48 (`av-lg`, drawers), 64 (`av-xl`, profile). `av-sq` for organisations and sites.

Status dot (`st`): 10px, `done` for online, `waiting` for away, bordered in `surface`. Stack (`av-stack`): overlap 8px, cap at four plus a "+n" avatar in `surface-3`.

Volunteers are never shown with a photo or a name on the marketing side; use the code avatar ("V-0412" in `av-sq`) there.
