# Ribbon

A ribbon labels a whole card, not a row. Three colours: `brand` (a fact about the card), `regulatory` (a gate the card is behind), `done` (a closed state). The corner ribbon (`ribbon-corner`) is for one-word live states on campaign and creative cards.

Text is 11px, 600, uppercase with 0.4px tracking. One ribbon per card. If you need two facts, use badges in the card body instead.
