# TopBar

48px, `surface`, `line` bottom edge. Left: a 20px `brand` square mark and the wordmark in 15px 600; the site switcher as a ghost button; the side badge. Right: search (240px, 32px tall, ⌘K hint), notifications with a count, the user avatar.

The studio variant carries the wall pill in `brand-dark` instead of the clinical badge, and the mark turns `brand-dark`. The bar always says which side of the boundary the screen belongs to; no screen mixes the two.
