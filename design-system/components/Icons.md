# Icons

A line set drawn on a 16px grid at 1.5px stroke with round caps and joins, in `currentColor`. Fifty glyphs are drawn here as inline SVG; copy the paths from this preview.

Sizes: 16px inside buttons, chips and table rows; 20px in the sidebar and top bar; 24px in empty states and module headers.

Colour: inherit the text colour at rest (`text-muted`), `ink` when active. The only coloured icons are the signal ones: `shield` and `clock` in `regulatory`, `check` in `done`, `warn` in `blocked`. A module icon sits in a 32px tile on `brand-wash`.

No filled icons, no two-tone, no emoji.
