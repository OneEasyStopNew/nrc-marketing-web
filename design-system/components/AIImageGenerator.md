# AIImageGenerator

Left: prompt, placement chips (the sizes Meta and Instagram accept), style chips, a standing `alert-info` that no people appear in generated images, the generate button with the per-image cost in the head. Right: a 2×2 result grid of Image frames: selected (`brand` ring), loading (Spinner), and rejected with a `badge-blocked` reason (a detected face). Actions: variations, download, use in creative.

The generated image enters the creative library with "Generated" as its rights state and still passes ComplianceCheck. The tool name in the head is generic; vendor names stay in settings.
