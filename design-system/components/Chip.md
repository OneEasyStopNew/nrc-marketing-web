# Chip

Chips are interactive pills: 28px tall, `radius-pill`, `line-strong` border. A chip toggles (`is-on` shows `brand-wash` ground, `brand` border and a leading check), filters, or holds a removable value with a trailing ✕.

Pills (`pill`) are 24px static labels for facts: phase, site count, languages. `pill-brand` for one emphasised fact; `pill-outline` for low-weight facts.

The **wall pill** (`wall`) is a special pill in `brand-dark` that marks any marketing-side surface: "Marketing side · no patient data". It appears in the top bar and on every studio card so nobody mistakes which side of the boundary they are on.

Rules: a chip holds one value; chips wrap, never truncate; use a Badge, not a chip, for a status.
