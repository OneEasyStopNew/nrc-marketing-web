# AICodeGenerator

A prompt line with Generate, a `codeblock` on `brand-dark` in IBM Plex Mono (keywords in a light blue, strings in a mint, comments in `on-dark-muted`), then Copy, Run in sandbox and Explain. The head states the language and that the API is read-only.

Scope: scripts for the accountant export, report queries and integration checks run by administrators. Generated code runs only in a sandbox with test data; credentials are injected there, never shown. Nothing generated here writes to the live database.
