# Input

36px tall, `line-strong` border, `radius-md`, 12px horizontal padding, 14px text. Label above in `body-medium`, helper text below in `caption-regular` (`text-faint`), error text in `blocked`.

States: focus swaps the border to `brand` and adds `shadow-focus`; error swaps the border to `blocked` and the ring to red; disabled sits on `surface-3` with `text-disabled`.

Icon inputs (`input-wrap`): 16px icon at left, text padded 36px. Addons (`input-addon`): a unit or prefix in `surface-3`, mono text.

Rules: one error message per field, written as the fix ("Enter ten digits"), not the fault. Never place a patient name field on a marketing-side form; the field does not exist there.
