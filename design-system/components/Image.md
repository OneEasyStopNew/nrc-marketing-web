# Image

Images sit in a `radius-lg` frame on `line` with a hatched `chart-muted` placeholder while loading or missing. Fix the aspect box (1:1 feed, 9:16 story, 16:9 landscape) so layouts do not jump. Captions in `caption-regular`.

A creative image carries its rights state: `badge-done` "Rights on file" or `badge-blocked` "Person recognisable" with the release reference it needs. No stock photography, no clip art.
